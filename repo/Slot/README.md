# AetherCLI: Terminal Slot Machine 🎰🚀

**AetherCLI** è un mini gioco in stile slot machine da terminale sviluppato in C++, con logica Docker integrata. Utilizza esclusivamente monete digitali gratuite (nessun denaro reale è coinvolto; ci si dissocia totalmente da qualsiasi forma di gioco d'azzardo). Il file di salvataggio locale è protetto da modifiche non autorizzate tramite un sistema di firma crittografica a checksum. I gettoni accumulati possono essere convertiti in codici di riscatto unici per sbloccare risorse e tool esclusivi nello store.

## 📥 Installazione automatica

Puoi installare rapidamente l'applicazione seguendo questi passaggi:

1. Visita il sito ufficiale [AetherCLI Hub](https://aether-cli-hub.vercel.app/) e scarica l'archivio `Slot.zip`.
2. Estrai il contenuto del file zip sul tuo computer.
3. Apri il terminale, entra all'interno della cartella estratta `Slot` ed esegui i comandi di configurazione:

```bash
# Rendi eseguibile lo script di installazione e avvialo
chmod +x install.sh
./install.sh
```
